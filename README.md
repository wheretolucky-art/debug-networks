# debug-networks

Apps for **Debug Networks**, CCTV and network services in Hazaribagh, Jharkhand. *We find it. We fix it.*

| Folder | What it is |
| --- | --- |
| [`dn-office/`](dn-office/) | DN Office, the owner's office app: clients, jobs, quotes, payments and follow-ups. Runs on Android as an APK. |
| [`gym-app/`](gym-app/) | PPL Coach, the owner's gym app: workouts, rest timer, bodyweight, diet and a weekly report. Runs on Android as an APK. |

Customer records and gym logs stay on the owner's phone and are never stored here.
